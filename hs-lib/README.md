# Peregrine Haskell library
This directory contains a Haskell library with the Peregrine AST and config type definitions and serializers/deserializers.
The library was extracted from the verified Rocq sources.

* [theories/](theories/): The Rocq sources used for extracting the Haskell library
* [extraction/](extraction/): Haskell code extracted from Rocq
* [src/LambdaBox/](src/LambdaBox/): Library interface, contains a cleaned up interface for the library
