# Rocq Frontend
This directory contains the Peregrine Rocq frontend, which is a wrapper around the MetaRocq erasure.
The frontend is implemented as a Rocq plugin written in OCaml using code extracted from Rocq.

* [src/](src/): contains plugin code extracted from Rocq
* [theories/](theories/): contains the code extracting the plugin to OCaml and defining the plugin
